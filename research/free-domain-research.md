## 二、方案 1：eu.org 免费域名 ⭐ 首选（永久免费）

### 关键事实（已核实）
- **永久免费**：1996 年运营的公益域名服务，域名永久免费（至少到 2030 年前不过期）
- **可托管 Cloudflare**：支持改 NS 到 Cloudflare（实测可用），这是关键 ✅
- **审核**：历史上一度中止（2025.2），但 **2026 年已恢复放水**（实测 2 天内通过，比预期快）
- **不限制数量**：每个账号可申请不限量 eu.org 域名
- **国内可访问**：可申请 `xx.cn.eu.org` 中国子域

### 申请流程（5 步）
1. 注册：https://nic.eu.org/arf/en/contact/create/ （用 Gmail/Outlook，避免 QQ 邮箱）
2. 验证邮箱 → 收到主题含 `FREE` 的确认邮件，点链接激活
3. 登录 → 点 "New Domain" → 填 `你的名字.eu.org`（如 `logs.eu.org`）
4. **关键环节**：填 NS。eu.org 不提供 DNS，需填 DNS 服务商地址
   - 推荐直接填 **Cloudflare 分配的 NS**（先注册 Cloudflare → 添加域名 → 拿到 2 个 NS 地址）
   - 验证级别选最简的 "Check for correctness of server names"（不做 SOA 验证，通过率高）
5. 等待人工审核 → 邮件通知通过 → 域名生效

### 注意
- 审核周期**不确定**（实测 2 天，最坏可能数周），需**提前申请**，不能等要用时才弄
- 需要 Cloudflare 账号（免费注册，无需认证）

## 三、方案 2：DNSHE 免费域名（立即可用，但一年一续）

### 关键事实（已核实）
- 每个账号注册 **5 个免费域名**，邀请他人再送 5 个
- **所有后缀（de5.net / cc.cd / ccwu.cc / us.ci）均可托管 Cloudflare**（2026 年初起）✅
- **2026 年起有效期改为一年一续**（不再是永久），到期需续
- 注册站点：https://my.dnshe.com/ （无需认证直接注册）
- Cloudflare 账号也无需认证

### 申请流程（3 步）
1. 注册 DNSHE → 左边 "Free Domains" → 选后缀 → 填子域名前缀 → confirm
2. 注册 Cloudflare → "添加域" → 输入 DNSHE 域名 → 选免费计划 → 拿到 NS 地址
3. 回 DNSHE 域名管理页 → "Name Servers" → 填入 Cloudflare NS → 等 10-30 分钟生效

### 注意
- 域名要 **1 年续一次**（不是永久），有失效风险
- 作为 **eu.org 审核期的过渡** 很合适

## 四、方案 3：is-a.dev（不适用，排除）

### 关键事实（已核实）
- 面向开发者的免费子域名，GitHub PR 方式申请（需 PR 审核合并）
- **不支持托管 Cloudflare**：只支持 CNAME 记录，NS 记录仅特批（服务商强制要求才给）
- **结论**：不能拿它建 Cloudflare named tunnel，**排除**

## 附：免费云托管补充（Emma 提到方向）

- **Fly.io**：免费 tier，每月 3 台共享实例，需绑卡（可后续解绑），**国内访问一般**
- **Render**：免费 web service，冷启动慢，需绑卡
- **Glitch**：免费，但资源少，不适合正式服务
- **Cloudflare Workers**：免费额度大（10 万请求/天），但**不适合跑完整 Blinko 后端**（无 SQLite 持久化、平台限制多）
- **结论**：免费云托管对"跑一个完整日志软件"不够用或不稳定，**不推荐作为主方案**；免费域名 + 本地 named tunnel 是当前最优
