## 1. 语义搜索 UI

### 1.1 位置
现有「🔍 搜索」Tab 增强，不新增入口。

### 1.2 搜索模式切换

搜索框上方加两个胶囊 Tab：

```
┌──────────────────────────────────────────┐
│  [🔤 关键词]   [🧠 语义搜索]             │  ← 模式切换
├──────────────────────────────────────────┤
│                                          │
│  ┌────── 搜索日记... ──────────────────┐ │
│  │  🔍                                   │ │  ← 搜索输入框
│  └───────────────────────────────────────┘ │
│                                            │
│  ── 搜索结果 ──                           │
└──────────────────────────────────────────┘
```

| 属性 | 值 |
|:-----|:----|
| 模式切换 | 两个胶囊 Tab：[🔤 关键词] [🧠 语义搜索] |
| 选中态 | `var(--accent-soft)` 背景，`var(--accent)` 文字 |
| 未选中 | `transparent` 背景，`var(--text-tertiary)` 文字 |
| 间距 | `gap-1`，`mb-2` |
| 切换行为 | 切换后搜索框 placeholder 和搜索逻辑改变 |

**关键词模式** — 现有实现不变，`diary.search` 按文本匹配

**语义模式** — 调用 `rag.search`，输入自然语言

### 1.3 输入框差异

| 模式 | placeholder | 搜索逻辑 |
|:-----|:------------|:---------|
| 🔤 关键词 | "搜索日记..." | `diary.search(title/content 包含关键词)` |
| 🧠 语义搜索 | "试试"上周开心的事"..." | `rag.search(query → embedding → vec 相似度 TOP 10)` |

### 1.4 搜索结果展示

#### 关键词模式结果（不变）
沿用现有 DiaryCard 样式，不做改动。

#### 语义搜索模式结果

```
┌──────────────────────────────────────────┐
│  🧠 语义搜索 · "上周开心的事"           │
│                                            │
│  ┌─ 日记卡片 ───── 📊 92% 相似度 ─────┐  │
│  │                                        │  │  ← 右上角相似度徽章
│  │  09:30                         🌿   │  │

│  │ 今天和朋友们去公园野餐，天气很好     │  │
│  │ 大家聊了很多关于旅行的计划，         │  │
│  │ <mark>开心</mark>的是终于定下了     │  │  ← 匹配段落高亮
│  │ ...                                  │  │
│  │                                        │  │
│  │ #朋友 #旅行    · 编辑  ·  ⋯          │  │

│                                            │
│  ── 共 8 条相关日记 ──                   │

```

#### 相似度徽章

| 属性 | 值 |
|:-----|:----|
| 位置 | 卡片右上角（与 mood emoji 同行右侧） |
| 显示 | 📊 N% — 如 `92%` |
| 字号 | 11px (`var(--font-size-xs)`) |
| 背景 | `var(--accent-soft)` |
| 颜色 | `var(--accent)`（绿色） |
| 圆角 | `rounded-lg`，`px-1.5 py-0.5` |
| 高相似度 | ≥80% 绿色，≥60% 黄色，<60% 灰色 |

#### 匹配高亮

| 属性 | 值 |
|:-----|:----|
| 高亮方式 | 在卡片正文中，AI 匹配的关键段落用 `<mark>` 样式标记 |
| 背景 | `var(--accent-soft)` |
| 文字色 | `var(--accent)` |
| 圆角 | `rounded` (4px) |
| 最大高亮 | 每篇展示前 2 个匹配段 |

#### 空态（没有匹配结果）

```
┌──────────────────────────────────────┐
│                                        │
│     🧠 没有找到语义匹配的日记          │
│                                        │
│     试试换个说法：                     │
│     「这周有什么收获」                │
│     「记录过关于旅行的内容」         │
│     「心情不好的时候写了什么」       │
│                                        │
└──────────────────────────────────────┘
```

| 属性 | 值 |
|:-----|:----|
| 引导文字 | "试试换个说法" + 3 个示例搜索词 |
| 示例样式 | 11px，`var(--accent)`，`cursor-pointer`，点击自动填入搜索框 |
| 图标 | 🧠 48px 居中 |

#### 加载态

搜索结果加载中，显示 3 个 skeleton 卡片（同 DiaryCard skeleton）。

## 2. 知识图谱可视化

### 2.1 位置
AI 总结 Tab 下方新增独立区域，或单独「🗺 图谱」Tab。推荐先用**AI 总结 Tab 内嵌区域**。

```
┌──────────────────────────────────────────────┐
│  [日报]  [周报]  [月报]  [年报]              │  ← 级别切换
├──────────────────────────────────────────────┤
│  （总结卡片区域）                              │
│                                              │
│  ── 知识图谱 ──                              │
│  ┌────────────────────────────────────────┐  │
│  │                                        │  │
│  │      🗺 知识图谱（节点-关系图）         │  │
│  │                                        │  │
│  │  🧑 咖啡馆  🏷️ 设计                   │  │
│  │    ╱      ╲                            │  │
│  │  📅 读书   💖 专注                     │  │
│  │    ╲      ╱                            │  │
│  │     📍 办公室                          │  │
│  │                                        │  │
│  └────────────────────────────────────────┘  │
│                                              │
│  ┌─ 关联日记 ───────────────────────────┐  │
│  │  选择节点查看关联日记                  │  │  ← 点击节点后展开
│  └────────────────────────────────────────┘  │
└──────────────────────────────────────────────┘
```

### 2.2 实体节点颜色

| 实体类型 | 颜色 | 色值 | emoji |
|:---------|:-----|:-----|:------|
| 人物 (person) | 蓝色 | `#60a5fa` | 🧑 |
| 事件 (event) | 橙色 | `#f97316` | 📅 |
| 地点 (place) | 绿色 | `#34d399` | 📍 |
| 情绪 (emotion) | 粉色 | `#f472b6` | 💖 |
| 主题 (topic) | 紫色 | `#a78bfa` | 🏷️ |

### 2.3 节点样式

```
  ┌──────────┐
  │  🧑 Alice │         ← 圆形节点 + emoji + 标签
  └──────────┘
       |
       |  关系线（mentioned_together / related_to / causes）
       |
  ┌──────────┐
  │  📅 读书  │
  └──────────┘
```

| 属性 | 值 |
|:-----|:----|
| 形状 | 圆形，按关联日记数缩放 40~80px |
| 文字 | 实体名，12px，`var(--text-primary)`，max 6 字 |
| 描边 | `2px solid` 与填充色一致 |
| 阴影 | `var(--shadow-card)` |
| 光标 | `pointer`，hover 放大 1.1x |
| 连线 | 关系名 10px 灰色标注 |
| 连线宽 | `2px`，`var(--border-default)` |

### 2.4 交互

| 交互 | 行为 |
|:-----|:------|
| hover 节点 | 放大 1.1x，tooltip 实体名+关联日记数 |
| 点击节点 | 高亮该节点及直接关联节点，其他半透明 |
| 点击节点后 | 下方展开关联日记列表 |
| 拖拽节点 | 力导向拖拽 |
| 双击空白 | 重置视图 |
| 滚轮 | 缩放 |

### 2.5 关联日记列表

## 4. 开发优先级

1. **语义搜索 UI**（P0）— 搜索模式切换 + 结果卡片 + 相似度徽章 + 高亮

## 5. 交互流程

```
🔍 搜索 Tab
  → 默认选中「关键词」模式（向后兼容）
  → 切换到「🧠 语义搜索」→ placeholder 变自然语言提示
  → 输入回车 → rag.search → 结果卡片 + 相似度徽章 + 高亮
  → 无结果 → 空态 + 示例引导

🤖 AI 总结 Tab
  → 总结卡片下方显示「知识图谱」区域
  → 有数据 → dagre 力导向图
  → 点击节点 → 高亮 + 展开关联日记
  → 无数据 → 空态引导
```
