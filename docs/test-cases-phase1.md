## F1 卡片日记

### F1.1 创建日记卡片（P0）

| 项目 | 内容 |
|------|------|
| **测试ID** | TC-F1-001 |
| **功能** | 创建一篇新日记 |
| **前置** | 应用已启动 |
| **步骤** | ① 点击「+」创建按钮 → ② 输入标题「测试日记标题」 → ③ 输入正文「这是一段测试正文」 → ④ 点击保存 |
| **预期结果** | 新卡片出现在时间线最顶部，标题显示「测试日记标题」，正文显示「这是一段测试正文」 |
| **类型** | 功能 / 正向 |

### F1.2 卡片展示格式（P0）

| 项目 | 内容 |
|------|------|
| **测试ID** | TC-F1-002 |
| **功能** | 卡片以卡片形式展示 |
| **步骤** | 创建多篇日记后，观察时间线 |
| **预期结果** | 每篇日记呈现为独立视觉卡片，包含：标题（如有）、正文预览、时间戳、标签（如有）。有圆角卡片的视觉边界 |
| **类型** | 视觉 / 正向 |
