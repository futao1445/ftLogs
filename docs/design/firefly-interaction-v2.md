## 设计总纲

**不是"按钮发光"，是"按钮是森林里的物体，做它该做的动作"**

### 场景设定
界面是**夜晚的森林**。用户像坐在森林空地中央，周围万物有灵。

- 导航 → 头顶树枝上挂着的叶片
- 操作 → 身边的萤火虫、飘落的叶子、滴落的露珠
- 内容 → 翻开落叶（日记）、注视水面（树洞）

### 核心约束（futao 明确）
1. ✅ 不要太暗——内容区必须清晰可读
2. ✅ 按钮是可识别的物体（叶、虫、羽、露），不是色块光点
3. ✅ 点击反馈是物体的"自然反应"，不是 scale/opacity

## 一、导航栏 Tab — 树枝挂叶

**形状**: 每片叶子挂在树枝上（底部细枝 + 叶形），选中叶发光

```
未选中:         选中（稳定发光）：    切换（光移动）：
    日记                ● 日记               日记
    日历                日历                  ● 日历
    ● 树洞   ←选中      树洞                 树洞
  
叶子干枯，灰色      叶子从叶脉发出          光从旧叶飘到新叶
                    柔和的暖绿光            （200ms ease-out）
```

### 实现规范

| 项目 | 值 |
|:-----|:----|
| 选中指示 | 不是底部横线，是叶子本身发光（`box-shadow: 0 0 12px rgba(74,222,128,0.4)` 扩散到周围 4px） |
| 未选中 | `color: var(--text-tertiary)`，无发光 |
| hover | 文字从灰变 `var(--text-secondary)`，微光 `0 0 6px rgba(74,222,128,0.15)` |
| 切换动画 | 光从旧 Tab 平移到新 Tab（`translateX`），旧叶渐暗-新叶渐亮，200ms ease |
| 叶子形状 | 不需要真实叶形，用文字模拟：`✏️ 日记 📅 日历 🔍 搜索 💬 树洞` — emoji 就是叶子本身 |

## 二、写日记按钮 — 羽毛笔

**形状**: 羽毛笔（用 `✒️` + 柔和背景模拟）。放在页面右下角的叶形底座上。

```
静止：                    点击（书写）：          完成保存：
  ✒️                         ✒️                    ✒️
  写日记                     写日记                  ✅ 已保存
┌──────┐              笔尖下泛出墨痕          笔尖闪一下金光
│ 底座  │              墨痕从笔尖扩散          底座发光确认
└──────┘              （300ms ease-out）
```

### 实现规范

| 项目 | 值 |
|:-----|:----|
| 底座形状 | 圆角卵石形（`rounded-2xl`），`bg-[var(--accent-soft)]` |
| 静止 | 笔 `✒️` + 文字"写日记"，13px，`var(--accent)`。底座光晕 4px |
| hover | 底座光晕扩散到 12px（`box-shadow: 0 0 14px var(--accent-soft)`），笔轻微上浮 2px |
| 点击 | 闪光两次——第一次"下笔"（短闪 80ms），第二次"收笔"（长闪缓缓消失 300ms）。墨痕效果用 `::after` 伪元素做圆形扩散 |
| 保存后 | `✅ 已保存`替换文字，笔尖闪金(`--gold`)，底座稳定发光 |

## 三、导航/Icon 图标按钮（💾 ✕ 🔄 👁️ 🗑️）

**形状**: 小萤火虫 — 在图标下方做极小光点

```
静止：          hover：            点击：
  💾               💾                💾
  保存             保存               保存
  · (小光点)       ◉ (光点变亮)      █ (光爆发后渐暗)
```

### 实现规范

| 项目 | 值 |
|:-----|:----|
| 光点位置 | 图标正下方，`w-1.5 h-1.5` (6px)，`rounded-full` |
| 默认 | 光点 `bg-[rgba(74,222,128,0.2)]` |
| hover | 光点变亮 `bg-[rgba(74,222,128,0.6)]`，`box-shadow: 0 0 6px rgba(74,222,128,0.4)` |
| 点击 | 光点爆发——0ms 光点放大到 12px（scale 2x），透明度 0.8；300ms 后缩回+渐暗 |
| 禁用状态 | 光点熄灭 `opacity-10`，图标 `opacity-30` |

## 四、主操作按钮（发送/确认/生成）

**形状**: 萤火虫光球 — 不是一个按钮，是一个"光在叫你去按它"

```
静止：                hover：              点击闪光：
┌──────────┐       ┌──────────┐         ┌──────────┐
│    ●     │       │    ◉     │         │    █     │
│  发送消息 │       │  发送消息 │         │  发送消息 │
│  光晕4px │       │ 光晕14px │         │ 光爆发   │
└──────────┘       └──────────┘         └──────────┘
```

### 实现规范

| 项目 | 值 |
|:-----|:----|
| 形状 | button 还是 `rounded-2xl px-5 py-2`，但背景 = 从中心到边缘径向渐变（中心亮、边缘暗），制造"光球"感 |
| 背景颜色 | `background: radial-gradient(circle at center, rgba(74,222,128,0.25) 0%, rgba(74,222,128,0.08) 100%)` |
| 静止 | 中心光点 4px，文字 `var(--accent)`。`border: 1px solid rgba(74,222,128,0.15)` |
| hover | 径向渐变中心从 25%→40% 亮度（不是 scale 放大，是光变强）。`box-shadow: 0 0 20px rgba(74,222,128,0.25)` |
| 点击闪光 | 1. 0ms: 光爆宽到 80px (`box-shadow` 瞬发) 2. 50ms: 文字变金色(`--gold`) 3. 250ms: 光恢复静止大小，文字恢复 accent 色 |
| 禁用 | 径向渐变消失，变为纯 `opacity-30`，无光晕无点击反馈 |

### 特殊：发送消息 — 萤火虫飞入

点击发送时，光球迸发出一颗光点，从发送按钮位置**曲线飞入**对话区最底部（然后消失）。

```
实现：用 framer-motion 做 animatePresence
<motion.div
  initial={{ opacity: 0, x: 发送按钮X, y: 发送按钮Y }}
  animate={{ 
    opacity: [0, 1, 1, 0],
    x: 对话区底部X, 
    y: 对话区底部Y,
    scale: [0.5, 1.2, 0.8, 0],
  }}
  transition={{ duration: 0.6, ease: "easeOut" }}
/>
```

## 五、引导 Chip/胶囊 Tab/分页按钮

**形状**: 落叶浮在水面 — 低饱和度、半透明、自然的椭形

```
静止（落叶浮在水面）：   hover（涟漪扩散）：      点击（水花溅起）：
┌──────────────┐      ┌──────────────┐        ┌──────────────┐
│ 🌱 了解生活  │      │ 🌱 了解生活  │        │ 🌱 了解生活  │
│ (水底模糊)   │      │ 水面清晰     │        │ 水花溅起+   │
└──────────────┘      └──────────────┘        │ 涟漪一圈(300ms)│
                                               └──────────────┘
```

### 实现规范

| 项目 | 值 |
|:-----|:----|
| 形状 | `rounded-full` 保留（已经有落叶的感觉，不改形状） |
| 静止 | `bg-[var(--accent-soft)]`（10% 透明度），`text-[var(--accent)]`。无边框 |
| hover | `bg` 从 10%→25%，文字更亮。`box-shadow: 0 0 10px rgba(74,222,128,0.15)` — 涟漪感 |
| 点击 | 1. 0ms: 周围扩散出一圈 1px 透明环（用 `::before` 做涟漪） 2. 环 300ms 扩散到 20px 然后消失 3. 背景回到 25% 再回到 10%（涟漪波纹感） |
| 选中态 | 不是变色，是**持续发光**（`box-shadow: 0 0 8px rgba(74,222,128,0.3)` 不变），背景 25% |

## 六、聊天气泡 — 月光下的水面

**形状**: AI 气泡像月光照亮的谈话气泡，用户气泡像水面反射

```
AI 气泡（月光照亮）：
┌──────────────────────────────────┐
│  🤖 下午好！想聊聊你最近的生活吗？ │
│  左侧有渐变的暖光流入             │
│  13:30                            │
└──────────────────────────────────┘

用户气泡（水面反射）：
               ┌──────────────────┐
               │  好呀，最近在忙   │
               │  项目收尾         │  ← 右侧有淡淡的反光
               │  13:31            │
               └──────────────────┘
```

### 实现规范

| 项目 | AI 气泡 | 用户气泡 |
|:-----|:---------|:---------|
| 背景 | `--bg-secondary` + 左侧边缘渐变 `linear-gradient(90deg, rgba(74,222,128,0.06) 0%, transparent 40%)` | `--accent-soft`，无额外光效 |
| 入场 | 光从左边缘流入 + 文字淡入（300ms ease-out）| 从右侧滑入（200ms ease-out）|
| 连续多条 | 只第一个 AI 气泡有光流入，后续无（光已经在了）|—|

### AI 思考态 — 萤火虫绕圈 + 月光

不再用三个点弹跳。AI 思考时：

```
┌──────────────────────────────────────┐
│                                        │
│     ●        ●                        │
│           ●       ●                  │  ← 5-8 颗极淡光点
│    ●                 ●               │     在一个小范围内随机漂浮
│         ●      ●                     │     每颗 2-4s 独立呼吸周期
│  （极小，半径 4px）                    │     位置偏差 ±10px
│                                        │
│  "正在思考..."（极淡灰色，11px）       │
└──────────────────────────────────────┘
```

> 这是**唯一**出现漂浮萤火虫的场景。不在空态也不在启动态加漂浮光点。
> 单颗最大 opacity 0.4，不叠加变亮。
