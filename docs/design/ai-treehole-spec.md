## 1. 产品概述

AI 树洞是一个**双向对话式 AI 助手**，整合日记 + 知识库 + 知识图谱 + 用户建模，让 futao 在聊天中了解自己的生活轨迹。

### 核心原则
- 不是 AI 总结日记，而是双向对话
- AI 不仅回答问题，也会主动提问了解用户
- 所有回答基于 futao 的真实日记数据（RAG + 图谱）
- 越聊 AI 越了解 futao（用户建模）

### 2.2 后端 — AI 树洞 API（林正树）

**数据模型**：

```
model TreeholeSession {
  id          Int      @id @default(autoincrement())
  title       String   // 自动生成："2026-07-30 对话"
  messages    String   // JSON: [{role, content, createdAt}]
  createdAt   DateTime @default(now())
  updatedAt   DateTime @updatedAt

  @@map("treehole_sessions")
}
```

**API 路由**：

| 方法 | 路由 | 说明 |
|:-----|:------|:------|
| query | `treehole.sessions` | 获取历史对话列表 |
| query | `treehole.messages` | 获取某次对话的所有消息 |
| mutation | `treehole.ask` | 发送消息，AI 结合上下文回复 |
| mutation | `treehole.newSession` | 新建对话 |
| mutation | `treehole.deleteSession` | 删除对话 |

**treehole.ask 逻辑**：

```
用户输入 "我最近工作状态怎么样"
  → 语义搜索 RAG（查询用户最近日记中工作相关内容）
  → 知识图谱查询（最近相关实体/主题）
  → 获取最近对话历史（当前 session 的消息）
  → 构造系统 prompt（包含：日记摘要 + 图谱数据 + 历史记录）
  → 调用 LLM
  → 返回 AI 回复
  → 保存到 treehole_sessions
```

**System Prompt 核心**：

```
你是一个温暖的 AI 树洞，用户的私人对话伙伴。你有以下数据源：
1. 用户最近的日记内容（摘要）
2. 用户的知识图谱实体（人物/事件/主题）
3. 对话历史

规则：
- 用温暖、朋友般的语气回应用户
- 基于真实日记数据说话，不凭空猜测
- 可以主动提问引导用户深入话题
- 如果用户提到日记中的内容，关联知识图谱数据
- 回复控制在 100-150 字，自然口语化
- 可以适当使用 emoji
```

### 2.3 用户建模（后续迭代）

- 从每次对话中提取用户的偏好、习惯、关注点
- 存储到 `user_profile` 表
- 每次调用 AI 时注入 profile 数据，让回答更有针对性
- Phase 2 功能：AI 能说"你上次提到在忙项目，现在完成了没？"

## 6. 知识库入口页面

### 6.1 入口位置

## 8. 交互反馈规范

### 所有可交互元素必须有反馈

| 操作 | 反馈类型 | 内容 |
|:-----|:---------|:-----|
| 点击发送消息 | 气泡弹出动画 | 用户气泡立即出现，typing indicator 出现 |
| AI 回复完成 | 气泡弹出动画 + 声音（可选） | AI 气泡 fade-in slide-left |
| 保存到知识库 | Toast | "✅ 已保存到知识库！" |
| 删除对话/知识 | 确认弹窗 | "确定删除？删除后无法恢复" + [取消] [确认删除] |
| 切换对话 | 内容切换动画 | cross-fade 200ms |
| 新建对话 | 清空聊天区 + 引导气泡 | 引导气泡 fade-in |
| 错误 | 错误气泡 | "⚠️ AI 暂时走神了" + 重试按钮 |
| AI 总结生成 | 总结区域 skeleton → fade-in | shimmer → 内容渐入 |

### Toast 规范

| 类型 | 图标 | 背景色 | 持续时间 |
|:-----|:-----|:-------|:---------|
| 成功 | ✅ | `var(--accent-soft)` | 3s |
| 错误 | ❌ | `rgba(239,68,68,0.1)` | 5s |
| 提示 | ℹ️ | `var(--bg-elevated)` | 3s |

### 动画参数

| 动画 | 时长 | 缓动 |
|:-----|:-----|:------|
| 气泡进入 | 300ms | `ease-out` |
| Toast 弹出 | 200ms | `ease-out` |
| 弹窗打开 | 200ms | `ease-out` |
| 列表切换 | 150ms | `ease-in-out` |
| button hover | 150ms | `ease` |
| **button 点击（tap）** | **150ms** | **`ease`** |

### 8.2 按钮点击反馈规范

> **重要**：在深色主题（`--bg-primary: #0f1a12`）下，**纯 scale 变化肉眼几乎不可见**。必须配合**颜色/亮度/阴影**三重变化。

所有可点击元素必须有点击反馈，避免"按了没反应"的感觉。仅 scale 不够——必须加颜色或内阴影。

#### 通用点击规则

| 属性 | 值 |
|:-----|:----|
| 点击瞬间 | `whileTap: { scale: 0.95, backgroundColor: (变暗), boxShadow: "inset 0 2px 4px rgba(0,0,0,0.3)" }` |
| 过渡时长 | `100ms`（非 150ms，要瞬发感） |
| 颜色变化 | 深色模式下必须有可见的色差（如 `#4ade80 → #22c55e`） |
| 内阴影 | 关键按钮加 `inset` 阴影，模拟"按下去"的物理凹陷 |

#### 按钮类型点击反馈对照表

| 按钮类型 | 点击态 (tap) — 三重变化 | 动画参数 |
|:---------|:------------------------|:---------|
| **主按钮**（accent 背景，如发送/保存/生成） | `scale: 0.95` + `backgroundColor: "#22c55e"`（更深绿） + `boxShadow: "inset 0 2px 4px rgba(0,0,0,0.4)"` | spring 500/10, 100ms |
| **次按钮**（文字色，如编辑/取消） | `scale: 0.95` + `color: "var(--accent)"` + `backgroundColor: "rgba(74,222,128,0.12)"` | spring 500/10, 100ms |
| **危险按钮**（红色 bg，如确认删除） | `scale: 0.95` + `backgroundColor: "#dc2626"`（更深红） + `boxShadow: "inset 0 2px 4px rgba(0,0,0,0.4)"` | spring 500/10, 100ms |
| **图标按钮**（💾 ✕ 👁️） | `scale: 0.82` + `backgroundColor: "rgba(74,222,128,0.15)"`（背景环瞬显） | spring 500/10, 100ms |
| **引导 chip** | `scale: 0.94` + `backgroundColor: "rgba(74,222,128,0.3)"`（从 10%→30%） | spring 500/10, 100ms |
| **导航 Tab** | `scale: 0.94` + `backgroundColor: "rgba(74,222,128,0.15)"` | spring 500/10, 100ms |
| **分页按钮** | `scale: 0.93` + `backgroundColor: "rgba(74,222,128,0.12)"` | spring 500/10, 100ms |
| **Toast 操作链接** | `scale: 0.95` + `opacity: 0.7` | spring 500/10, 100ms |

#### 实现要点（framer-motion）

```tsx
// 主按钮（三重变化：scale + 颜色 + 内阴影）
<motion.button
  whileHover={{ scale: 1.03, backgroundColor: "#4ade80" }}
  whileTap={{
    scale: 0.95,
    backgroundColor: "#22c55e",
    boxShadow: "inset 0 2px 4px rgba(0,0,0,0.4)",
  }}
  transition={{ type: "spring", stiffness: 500, damping: 10, duration: 0.1 }}
/>

// 图标按钮（收缩 + 背景环）
<motion.button
  whileHover={{ scale: 1.08, backgroundColor: "rgba(74,222,128,0.08)" }}
  whileTap={{
    scale: 0.82,
    backgroundColor: "rgba(74,222,128,0.15)",
  }}
  transition={{ type: "spring", stiffness: 500, damping: 10, duration: 0.1 }}
/>

// 引导 chip
<motion.button
  whileHover={{ scale: 1.03 }}
  whileTap={{
    scale: 0.94,
    backgroundColor: "rgba(74,222,128,0.30)",
  }}
  transition={{ type: "spring", stiffness: 500, damping: 10, duration: 0.1 }}
/>

// CSS 后备
.btn:active {
  transform: scale(0.95);
  filter: brightness(0.85);
  transition: transform 100ms ease, filter 100ms ease;
}
```
