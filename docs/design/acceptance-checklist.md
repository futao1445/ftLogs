## 总评计算

```
总得分 = Σ(各验收项得分 × 权重)
不合格 < 60分   → 需修复后重新验收
60分 ≤ 合格 < 80分
优秀 ≥ 80分
```

每项得分规则：
- 不合格 = 0 分（功能不可用或缺失）
- 合格 = 1 分（功能可用，有错误引导）
- 优秀 = 2 分（功能完整+引导完善+无静默失败）

## Amily 测试 checklist

### 每天/每次构建后必测

```
□ 验收链接可打开（200）
□ 写一条日记可保存
□ 时间线刷新显示新日记
□ 暗色模式切换正常
□ Build 无 error
```

### 新功能上线必测

```
□ 功能正常路径可用
□ 功能异常路径有引导（非静默失败）
□ 修改不破坏相邻功能
□ 所有错误态展示用户可读的提示
□ 移动端/桌面端至少测一种
```

### 回归测试（每周）

```
□ P0 全部功能（CRUD/搜索/日历/时间线）
□ LLM 配置 + AI 总结生成
□ 语义搜索/知识图谱
□ 导出功能
□ 清除测试数据
```
