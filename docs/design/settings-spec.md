```
│                       │
│                       │
│  ┌ 设置面板 ───────┐ │
│  │ ⚙️ 设置    ✕    │ │
│  │                 │ │
│  │  ├─ 通用        │ │
│  │  │  • 主题       │ │  ← 快捷切换（与导航栏 toggle 联动）
│  │  │  • 界面语言   │ │  ← 预留，暂只支持 zh-CN
│  │  │               │ │
│  │  ├─ LLM 配置     │ │  ← 核心配置项
│  │  │  • API 地址    │ │
│  │  │  • API Key    │ │
│  │  │  • 模型       │ │
│  │  │               │ │

│  │  │               │ │
│  │  └─ 关于         │ │

│  │     • 数据存储   │ │
│  └──────────────────┘ │
└────────────────────────┘
```

### 标注
| 属性 | 值 |
|------|----|
| 类型 | 右侧滑入 Drawer（非全屏弹窗） |


## 4. LLM 配置 — 平台选择器 + 独立配置

### 结构
LLM 分组内第一行是**平台选择器**（下拉菜单），选中后显示对应平台的配置。用户只用一个平台，不是同时配多个。

```
├─ LLM 配置
│
│  AI 平台
│  ┌──────────────────────────┐
│  │  DeepSeek           ▼    │  ← 下拉选择器
│  └──────────────────────────┘
│
│  ── 当前: DeepSeek ─────────
│
│  API Key
│  ┌────────────────────────────────┐
│  │ sk-********************       │  ← password input
│  └────────────────────────────────┘
│
│  模型
│  ┌────────────────────────────────┐
│  │ deepseek-chat         ▼       │  ← select
│  └────────────────────────────────┘
│
│  [ 测试连接 ]    [ 💾 保存 ]
│
│  ── 测试结果 ────────────────
│  ✅ 连接成功（deepseek-chat, 延迟 320ms）
│  ───────────────────────────────
```

### 平台选择器

| 属性 | 值 |
|------|----|
| 类型 | 原生 `<select>` 或自定义下拉框 |
| 宽度 | 100% |
| 高度 | `h-10` |
| 圆角 | `rounded-lg` (8px) |
| 背景 | `var(--bg-secondary)` |
| 文字 | `var(--text-primary)` |
| 选项 | DeepSeek、Kimi、阿里云、自定义 |
| 选中后 | 下方显示对应平台的配置表单 |

### 选项切换行为
- 用户切换平台时：
  - 如果当前平台有已保存的配置 → 自动填充已保存的 API Key（隐藏显示「••••••••••」）和模型
  - 如果当前平台没有配置 → 显示空字段
  - 切换后之前平台的测试结果清除
  - 切换不触发自动保存

### 交互流程

1. 用户选择平台 → 填写 API Key → 点击「获取模型列表」
2. 调后端 `/llm.models`（用已保存的 API Key 去调对应平台的 /models 接口）
3. 成功 → 模型下拉自动填充选项
4. 失败 → 显示错误提示，模型下拉显示可手写的输入框

```
[     填写 API Key / API Key ...       ]
[        模型（点击获取模型列表）         ]
┌────────────────────────────────────────┐
│  [ ↻ 获取模型列表 ]                    │
│  ────────────────────────────────────── │
│  模型                                  │
│  ┌────────────────────────────────────┐ │
│  │ deepseek-chat    ▼                │ │  ← 获取成功后填充
│  └────────────────────────────────────┘ │
└────────────────────────────────────────┘
```

### 获取模型列表按钮

| 属性 | 值 |
|------|----|
| 位置 | 模型字段上方或与模型字段同行（上图方案：在模型字段上方独立一行） |
| 图标 | ↻（刷新）或文字"获取模型列表" |
| 样式 | 文字按钮，13px，`var(--accent)`，`cursor-pointer` |
| 调接口 | `api.llmModels(provider)` — 后端用已保存的 API Key 调对应平台 /models |
| 成功 | 下拉填充模型选项列表 |
| 失败 | 显示错误文字（红色），模型字段变为可手写的文本输入框 |
| 禁用条件 | API Key 为空时按钮 disabled + "请先填写 API Key" tooltip |

### 模型字段

| 属性 | 值 |
|------|----|
| 默认态 | 显示"点击「获取模型列表」加载"（灰色占位文字） |
| 获取成功 | 变为 `<select>` 下拉，填充动态模型列表 |
| 获取失败 | 变为手写 `<input type="text">`，placeholder="获取失败，请手动输入" |
| 已保存配置回填 | 如果之前已保存过模型，直接显示该模型名（不占位） |

### 各平台固定配置

> 注意：模型列表不再硬编码，通过 API 动态获取。以下仅列出 API 地址等固定信息。

| 平台 | API 地址（自动填充，不可编辑） | 默认模型 | Key 命名 |
|:-----|:-----|:----------|:----------|
| DeepSeek | `https://api.deepseek.com` | deepseek-chat | `DEEPSEEK_API_KEY` |
| Kimi | `https://api.moonshot.cn/v1` | moonshot-v1-8k | `MOONSHOT_API_KEY` |
| 阿里云 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | qwen-plus | `DASHSCOPE_API_KEY` |
| 自定义 | 用户填写 | 用户选择/输入 | 用户命名 |

### 各平台配置项

#### DeepSeek
| 字段 | 类型 | 默认值 |
|:-----|:-----|:-------|
| API 地址 | 固定显示 | `https://api.deepseek.com` |
| API Key | password input | 空 |
| 模型 | select | `deepseek-chat`, `deepseek-reasoner` |

#### Kimi
| 字段 | 类型 | 默认值 |
|:-----|:-----|:-------|
| API 地址 | 固定显示 | `https://api.moonshot.cn/v1` |
| API Key | password input | 空 |
| 模型 | select | `moonshot-v1-8k`, `moonshot-v1-32k`, `moonshot-v1-128k` |

#### 阿里云
| 字段 | 类型 | 默认值 |
|:-----|:-----|:-------|
| API 地址 | 固定显示 | `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| API Key | password input | 空 |
| 模型 | select | `qwen-plus`, `qwen-max`, `qwen-turbo` |

#### 自定义
| 字段 | 类型 | 默认值 |
|:-----|:-----|:-------|
| 名称 | text input | 空（例："我的 OpenAI"） |
| API 地址 | text input | 空（例：`https://api.openai.com/v1`） |
| API Key | password input | 空 |
| 模型 | text input 或 select | 空（例：`gpt-4o-mini`） |

自定义平台比前三个多一个`名称`字段，用于标识这个自定义配置。

### 保存逻辑
- 每个平台独立保存，key 命名：`llm_provider_deepseek`, `llm_provider_kimi` 等
- 保存时只保存当前平台的数据，不影响其他平台
- 每个平台的数据存为一个 JSON 对象：`{ apiKey, model }`（API 地址固定无需存）
- 自定义平台额外存 `{ name, baseUrl, apiKey, model }`

### 测试结果

## 8. 交互流程总结

```
点击齿轮 ⚙️
  → SettingsDrawer 从右侧滑入（遮罩覆盖）
  → 默认显示通用分组 + LLM 配置折叠
  → 点击 LLM 配置分组展开
  → 填写 API Key / URL / 模型
  → 点击「测试连接」验证
  → 点击「保存」持久化（存 config 表）
  → 关闭 drawer
  → 导航栏主题 toggle 与此面板内的主题选择双向同步
  → 点击遮罩或 ✕ 关闭
```

### 快捷键
- `ESC` 关闭 drawer
- 焦点在 drawer 内部，关闭后回到之前焦点位置
