## 1. AI 总结 Tab — 独立页面 + 卡片式布局

### 核心原则
1. **独立 Tab** — 不在时间线内联，导航栏新增「🤖 AI」Tab
2. **卡片式** — 总结内容像日记卡片一样垂直排列
3. **手动触发** — 所有总结必须用户点击按钮后才生成，不自动读取日记
4. **多层递进** — 每级总结的输入下一级的输出（避免上下文过长）
   - 日总结 ← 当天原始日记
   - 周总结 ← 7 天日总结
   - 月总结 ← 4~5 周周总结
   - 年总结 ← 12 个月总结
5. **内容结构** — 身体/精神/心理/成长 + 建议 + 修改按钮
6. **持久化** — 总结保存到数据库，跨层级引用已保存数据
7. **双重修改** — 直接编辑原文 + AI 重新生成

### 级别切换栏

```
[ 日报 ]  [ 周报 ]  [ 月报 ]  [ 年报 ]
```

| 属性 | 值 |
|:-----|:----|
| 布局 | 横向 `flex`，`gap-1`，居中 |
| 样式 | 胶囊按钮 `rounded-lg`，`px-3 py-1.5`，`text-sm` |
| 未选中 | `var(--bg-secondary)` 背景，`var(--text-tertiary)` 文字 |
| 选中态 | `var(--accent-soft)` 背景，`var(--accent)` 文字，`font-medium` |
| 过渡 | `all 150ms ease` |

### 级别数据

| 级别 | 时间指示 | 输入来源 | 触发前提 |
|:-----|:---------|:---------|:---------|
| 日报 | 当天日期 | 当天原始日记 | 当天有日记 |
| 周报 | 第N周 (M月DD日~M月DD日) | 本周7天的日总结 | 本周有≥1条日总结 |
| 月报 | 2026年N月 | 本月4~5周的周总结 | 本月有≥1条周总结 |
| 年报 | 2026年 | 12个月的月总结 | 本年有≥1条月总结 |

## 6. 交互流程

```
点击导航栏 🤖 AI
  → 切换到 SummaryPage
    → 默认显示上次查看的级别（如周报）
    → 检查该时间段是否有总结数据
      → 有：显示总结卡片（可编辑/重新生成/复制）
      → 无且有日记数据：显示空态 + 生成按钮
      → 无日记数据：全空提示
    → 切换级别（日/周/月/年）：重新请求该级别的总结
    → ◀ ▶ 切换时间范围：同级别不同时间段
    → 点击编辑：文本变 textarea → 保存/取消
    → 点击重新生成：展开反馈输入 → 取消/重新生成
    → 下方列表显示历史总结（翻页/懒加载）
```
