## 2. 日记卡片组件

### 基本结构（所有状态共用）

```
┌──────────────────────────────────────┐
│ 顶部：时间 + 心情 + 更多按钮         │ ← h-5
├──────────────────────────────────────┤
│ 正文预览 / 缩略图                     │ ← 弹性
│                                       │
├──────────────────────────────────────┤
│ 底部：标签 + 操作按钮                 │ ← h-8
└──────────────────────────────────────┘
```

### 组件属性表

| 属性 | 值 |
|------|----|
| 宽度 | 100% (flex-1) |
| 圆角 | `border-radius: var(--radius-card)` |
| 背景 | `var(--bg-secondary)` |
| 边框 | `1px solid var(--border-default)` |
| 内边距 | `padding: 16px` |
| 内部间距 | `gap: 12px` |
| 阴影 | `var(--shadow-card)` |
| hover | 微上升 `-translate-y-0.5` + 边框变亮 `var(--border-hover)` |

### 各状态

#### 空状态（新日记）
```
┌──────────────────────────────────────┐
│ ＋  写点什么...   今日心情 →  😊🌿🔥│
└──────────────────────────────────────┘
```
- 占位文本：`var(--text-placeholder)`
- 背景：半透明虚线边框

#### 纯文字卡片
```
┌──────────────────────────────────────┐
│ 09:30                            🌿  │  ← 时间+心情
│ ────────────────────────────────     │
│ 今天在咖啡馆看完了《设计的生态学》   │  ← 正文预览
│ 第三章，感触很深。这本书讲了...      │  ← 最大 3 行
│ 查看更多 →                           │  ← 超过 3 行时出现
│                                      │
│ #读书 #设计     ·  编辑  ·   ⋯       │  ← 标签  操作
└──────────────────────────────────────┘
```
- 正文 max 3 行，`line-clamp-3`
- 超出显示「查看更多 →」

#### 有图卡片
```
┌──────────────────────────────────────┐
│ 09:30                            🌿  │
│ ────────────────────────────────     │
│ 今天拍到的落日                       │
│                                      │
│  ┌────┐ ┌────┐ ┌────┐  +2          │  ← 图片缩略图行
│  │    │ │    │ │    │               │
│  └────┘ └────┘ └────┘               │  ← 60x60px 圆角8px
│                                      │
│ #摄影 #日常    ·  编辑  ·  ⋯         │
└──────────────────────────────────────┘
```
- 缩略图：`60x60px`，`rounded-lg`
- 最多显示 3 张 + 剩余数量标记
- 点击展开全部

#### 编辑态（点击卡片/写新日记弹窗）

## 6. 响应式行为

| 断点 | 布局 | 说明 |
|------|------|------|
| < 640px (手机) | 时间线竖排，单列 | 全宽卡片 |
| 640-1024px (平板) | 时间线竖排 | 左右 padding 增大 |
| > 1024px (桌面) | **2 列瀑布流** | 切换为 columns-2 布局 |
| 编辑态 | 全屏弹窗 | 始终居中，遮罩层 |

---

## 7. 动画 & 交互

| 元素 | 动画 | 时长 |
|------|------|------|
| 卡片 hover | translateY(-2px) + shadow 加深 | 200ms ease |
| 翻页/新日记 | fade-in + slide-up | 300ms ease-out |
| 弹窗打开 | scale(0.95→1) + fade | 250ms ease-out |
| 导航切换 | color + border 过渡 | 150ms ease |
| 图片上传 | 淡入 | 200ms ease |
| 搜索输入 | 结果防抖 + 平滑出现 | 200ms delay |

## 8. 图标系统

不使用图片图标，全部使用 SVG 内联：
- 心情：6 个定制 SVG（🌿 😊 😢 🔥 💡 ✨）
- 导航：diary/calendar/search/user 手写 SVG
- 操作：edit/trash/more/share SVG
- 空状态：定制 SVG 插画（一片叶子/一盏灯）

风格：2px stroke, round cap, 圆润线条，与 futao-homepage 一致。
