## 1. 字数统计 — DiaryEditor

### 位置
编辑器右下角，textarea 底部外侧，和 Markdown 语法提示同一行右侧。

### 设计
```
┌─────────────────────────────────────┐
│ Markdown 编辑器区域                  │
│                                     │
│                                     │
└─────────────────────────────────────┘
  **加粗** *斜体*      已写 128 字     ← 右下角对齐
```

### 标注
| 属性 | 值 |
|------|----|
| 位置 | textarea 容器右下角，`text-right` |
| 字体 | `var(--font-mono)` |
| 字号 | 11px (`var(--font-size-xs)`) |
| 颜色 | `var(--text-tertiary)` |
| 显示 | `"已写 {n} 字"` (中文字数, `Array.from(content).length`) |
| 更新 | 每次 `onChange` 实时更新 |
| 0 字 | 不显示（或显示 `已写 0 字` 半透明） |

### 实现位置
`DiaryEditor.tsx`，在 textarea 容器底部与语法提示同行。

## 2. 历史上的今天 — Timeline 提示卡片

### 位置
时间线页面顶部，日期标题下方，首张日记卡片上方。

### 状态

#### 有回顾内容
```
┌──────────────────────────────────────────┐
│  📅 去年今天                              │
│                                          │
│  你写了「设计的生态学第三章读完了…」       │
│                                          │
│  [查看完整日记 →]                         │
└──────────────────────────────────────────┘
```

| 属性 | 值 |
|------|----|
| 背景 | `var(--accent-soft)` |
| 边框 | `1px solid var(--accent-border)` |
| 圆角 | `var(--radius-card)` (12px) |
| 内边距 | `p-4` (16px) |
| 图标+标题行 | 📅 + "去年今天" 标题，`font-size-sm` |
| 预览文字 | 截取第一条日记前 60 字 + "…"，`text-sm` |
| 查看按钮 | `"查看完整日记 →"`，accent 色，14px |
| 点击行为 | 滚动到对应日期/打开日记详情 |
| 动画 | fade-in + slide-down，300ms |

#### 无回顾内容（不显示）
- 如果没有往年同日日记，不渲染此组件
- 组件在渲染前检查 `pastDiaries.length === 0` 则 `return null`

### 多篇回顾
如果去年同日有多篇日记：
- 预览文字显示最近一篇的摘要
- 查看后进入完整日记列表（按当天日期过滤）

### 实现位置
`DiaryTimeline.tsx` 头部，日期标题下方。

## 3. 标签筛选器 — PageShell

### 位置
搜索栏旁边，同一行右侧。

### 布局
```
┌──────────────────────────────────────────┐
│  🔍 搜索日记...    全部 ▼  #读书 #设计  │
└──────────────────────────────────────────┘
```

### 状态

#### 默认态 — "全部" 标签
```
[ 全部日记 ]  #读书  #设计  #摄影  #日常
 ^^^^^^^^^^
 默认选中，无边框高亮
```

| 属性 | 值 |
|------|----|
| 默认标签 | `全部日记`（灰色胶囊） |
| 可选标签 | 从现有标签列表动态渲染 |
| 标签样式 | 胶囊形 `rounded-full`，`px-3 py-1` |
| 未选中 | `background: var(--bg-secondary)`，`color: var(--text-secondary)` |
| 选中态 | `background: var(--accent-soft)`，`color: var(--accent)` |
| 选中态字体 | `font-medium` |
| 间距 | `gap-2` |
| 滚动 | 横向 `overflow-x-auto`，无滚动条 |

#### 选中某个标签后
```
 全部日记  [ #读书 ]  #设计  #摄影  #日常
```

- 下方 timeline 自动过滤为该标签的日记
- 标签切换后保持当前视图状态（不重置滚动位置）
- 点击「全部日记」恢复显示所有

### 后端参数
调用 `diary.list({ tagId: selectedTagId })`（后端已支持）。

### 数据获取
页面加载时调用 `tag.list` 获取所有标签列表。

## 4. 导出按钮 + 导出记录

### 位置
时间线页面顶部，日期标题右侧（「新日记」按钮左侧）。

### 设计
```
◈ 今天 07/29        [📥] [＋新日记]
                     ^^^^ 导出按钮
```

### 按钮
| 属性 | 值 |
|------|----|
| 图标 | 下载 SVG：向下箭头 + 方形底 |
| 大小 | 20x20px，与「新日记」按钮等行高 |
| 点击行为 | 触发后端导出 API `POST /api/trpc/export.export` |
| 状态 | 导出中显示 loading spinner |
| 行为 | 导出成功 → 刷新导出记录列表 / 显示 Toast 提示 |
| Toast 提示 | "导出完成，正在生成..." + 自动消失 3s |

### 导出记录列表（可选：放在设置/导出页）
如果实现导出记录列表，设计：

│ │                   [ 下载 ]      │   │

## 5. LLM 配置页（Phase 2 预告）

### 位置
设置入口 → 全屏弹窗或独立页面。

### 布局结构
```
┌──────────────────────────────────────┐
│ ⚙️ LLM 配置        [ ✕ 关闭 ]        │
├──────────────────────────────────────┤
│                                      │
│ API 地址                              │
│ ┌────────────────────────────────┐   │
│ │ https://api.openai.com/v1     │   │
│ └────────────────────────────────┘   │
│                                      │
│ API Key                               │
│ ┌────────────────────────────────┐   │
│ │ sk-********************       │   │
│ └────────────────────────────────┘   │
│                                      │
│ 模型                                  │
│ ┌────────────────────────────────┐   │
│ │ gpt-4o-mini    ▼              │   │
│ └────────────────────────────────┘   │
│                [ 💾 保存 ]            │
└──────────────────────────────────────┘
```

| 属性 | 值 |
|------|----|
| 背景 | `var(--bg-elevated)` |
| 圆角 | `var(--radius-card)` (12px) |
| 输入框 | `h-10`，`px-4`，背景 `var(--bg-secondary)` |
| 输入框焦点 | 边框变 `var(--accent)` |
| API Key 输入 | `type="password"` |
| 保存按钮 | accent 色，全宽或右对齐 |
| 模型选择 | 下拉菜单含常见模型（gpt-4o-mini, claude-3-haiku, deepseek-chat 等 + 自定义输入）|
