## 核心思考

### 这次跟灵感主页的萤火之森有什么不同？

上次的问题是：**深色铺了整个页面**。氛围是对的但每次看都要"适应亮度"。

这次的核心策略：
```
萤火虫的光 → 只用在交互反馈上，不铺在背景上
内容区 → 保持现有清晰的对比度和可读性
暗色氛围 → 只用于加载态、等待态、沉浸态（树洞聊天AI思考时）
```

### 设计语言：一粒萤火虫的故事

每颗萤火虫有一个**呼吸周期**：
```
暗(0.3s) → 渐亮(0.5s) → 亮(0.4s) → 渐暗(0.3s) → 暗
```

交互借用这个节奏：
- **hover** = 萤火虫"注意到你"，亮度从 30% → 70%
- **点击** = 萤火虫"闪光应答"，瞬间 100% 亮度后恢复
- **等待/加载** = 萤火虫群缓缓漂浮，随机明灭
- **完成/成功** = 萤火虫们同步亮一下
- **删除/消失** = 光点黯淡、飘走

## 一、明暗区域划分

```
┌───────────────────────────────────────────────┐
│  区域A：内容区（高对比度、明亮、可读）        │
│  ┌─────────────────────────────────────────┐  │
│  │  日记文字 / 搜索结果 / 菜单选项        │  │  │  ← bg-light / 文字高对比
│  │  用户气泡 / 编辑框 / 设置              │  │  │
│  └─────────────────────────────────────────┘  │
│                                                │
│  区域B：交互层（萤火虫发光层，半透明叠加）    │
│  按钮、Tab、chip 的光晕反馈在此层             │
│                                                │
│  区域C：氛围层（仅在沉浸态时出现）             │
│  AI思考中 / 加载 / 空态 / 树洞聊天区背景      │  ← 暗色底 + 飘浮光点
└───────────────────────────────────────────────┘
```

### 三区域对比

| 区域 | 背景亮度 | 用途 | 萤火虫效果 |
|:-----|:---------|:-----|:-----------|
| 内容区 A | 现有亮度（或微调更亮） | 日记、气泡、搜索、设置 | 无光效，保持清晰 |
| 交互层 B | 透明叠加 | 所有可点击元素 | 光晕反馈在此层 |
| 氛围区 C | 暗色（--bg-primary 附近） | AI思考、空态、加载 | 漂浮萤火虫+缓缓明灭 |

## 二、交互元素设计

### 2.1 主操作按钮（发送/保存/生成/新对话）

**形状理念**：不是长方形，是柔和的光团/卵石形（圆角极大，不规则的柔光边缘）

```
按前的静止态：           hover态：                点击闪光态：
┌──────┐               ┌──────┐               ┌──────┐
│ ○○○  │               │ ◉◉◉  │               │ ███  │
│ 发送  │               │ 发送  │               │ 发送  │
└──────┘               └──────┘               └──────┘
暗淡光晕              光晕扩大+变暖           瞬间闪光(100%)
                       色温变暖                然后渐暗恢复
```

**光晕颜色**：`rgba(74, 222, 128, X)` — 根据状态 X 变化

| 状态 | 光晕透明度 | 光晕半径 | 色温 |
|:-----|:-----------|:---------|:-----|
| 默认 | 15% | 4px | 中性绿 |
| hover | 35% | 12px | 暖绿偏金 |
| 点击 flash | 80%→15% | 20px→4px | 金色 |
| 禁用 | 8% | 2px | 冷灰 |

**交互流程时序**：
```
点击瞬间 (0ms)  →  光晕爆发到 80% + 扩散到 20px + 色温变金
恢复期 (0~300ms) →  光晕从 80% 渐降到 15%，半径从 20px 缩回 4px
完全恢复 (300ms)  →  回到默认态
```

> 注意：点击时按钮本身的文字/图标保持可读，闪光在外围光晕层，不在文字层。
> 这样用户看到"按钮闪了"但内容没被遮住。

---

### 2.2 图标按钮（💾 ✕ 👁️ 🗑️）

**形状理念**：小光点，半透明圆形底

```
静止态：                   hover态：               点击态：
   ○                        ◉                      █
微微可见的圆点          光晕亮起，略放大      闪光爆发后缩小
```

| 属性 | 值 |
|:-----|:----|
| 形状 | 圆形，`w-7 h-7`（28px） |
| 默认 | 半透明 `opacity-40`，无背景 |
| hover | 背景 `rgba(74,222,128,0.1)` 出现，图标变亮 |
| 点击 | 背景爆发 `rgba(74,222,128,0.25)` 250ms，然后渐隐 |
| 闪光颜色 | 金色偏绿（暖光感） |

---

### 2.3 引导 Chip / 胶囊 Tab

**形状理念**：不规则的卵石/树叶形

```
静止：                                           hover：
┌────────────────────┐                     ┌────────────────────┐
│  🌱 了解我的生活   │  ← 只有文字+微光     │  🌱 了解我的生活   │
└────────────────────┘                     └────────────────────┘
                                             光晕轮廓柔和亮起
```

| 属性 | 值 |
|:-----|:----|
| 默认 | 文字色 `var(--text-secondary)` + `var(--accent-soft)` 背景 |
| hover | 背景亮度 +20%（不增绿，而是更暖），光晕从边缘扩散 |
| 点击 | 类似萤火虫闪光一次（光从中心向四周脉冲扩散） |
| 选中态 | 持续发光（稳定的 40% 光晕）而非变色 |

与现有设计的区别：**hover 不是变色，而是边缘光晕扩散**。整个 chip 就像一个微型的卵石，萤火虫停在上面发光。

---

### 2.4 导航 Tab（✏️ 日记 📅 日历 🔍 搜索 💬 树洞）

**形状理念**：每片叶子或每颗萤火虫的栖息地

```
未选中：
  日记   日历   搜索  ● 树洞    ← 当前选中态持续发出柔和绿光
                                 不选中态只有文字无光晕

切换动画：
  从旧 Tab 的光晕 → 缓慢漂移到新 Tab 下方 → 在新 Tab 下方稳定发光
  （像萤火虫从一片叶子飞到另一片叶子）
```

| 状态 | 表现 |
|:-----|:------|
| 未选中 | 只有灰色文字，无光效 |
| hover | 底部出现微弱光晕（10%），前 100ms |
| 选中（默认） | 底部持续光晕 2px（与现有 `bottom-line` 区别在于：不是实线，是**渐变的发光条**）|
| 切换动画 | 光从旧 Tab 下方水平移动到新 Tab 下方（200ms ease） |
| 点击 | 光晕闪烁一次（亮度 40%→80%→40%） |

这与现有底部线的区别：**底部是发光的渐变条，不是实线颜色**。

---

### 2.5 聊天气泡（树洞 AI / 用户）

**形状理念**：发光的对话区域，各自有不同的光态

```
AI 气泡（左侧）：
┌──────────────────────────────────────┐
│  🤖 下午好！想聊聊你最近的生活吗？    │
│                                       │  ← 左侧有一道超淡的暖光
│  13:30                                │     像月光照在对话上
└──────────────────────────────────────┘

用户气泡（右侧）：
                ┌──────────────────────┐
                │  好呀，最近在忙项目   │
                │                      │  ← 右侧用户气泡无光效
                │  13:31               │     保持清晰文字
                └──────────────────────┘
```

| 属性 | AI 气泡 | 用户气泡 |
|:-----|:---------|:---------|
| 光效 | 左侧边缘有极淡的暖光渐变（像月光） | 无光效，纯文字 |
| 气泡进入 | 光从左侧流入+文字淡入（300ms） | 从右侧滑入（200ms） |

**AI 回复生成中的萤火虫**：
```
当 AI 正在思考时，不是三个点弹跳：
而是三颗萤火虫在气泡位置缓缓上浮、明灭
（每颗 0.5s 随机呼吸周期，位置有微小漂移）

 ● （亮）                        ● （暗）
    ● （渐亮）  → 3s后 →    ● （渐亮）
       ● （暗）                    ● （亮）
    ↑ 三颗随机明灭              ↑ AI回复出来了，光点扩散消失
```

---

### 2.6 知识库条目卡片

**形状理念**：光晕书签，按新旧的发光强度

```
最新保存（发光最强）：
┌─────────────────────────────────────────┐
│  "最近工作压力有点大"                    │
│  2026-07-30 14:00 · 来自树洞对话        │  ← 左侧光晕条（暖绿渐变）
│  [👁️ 查看] [✏️ 编辑] [🗑️ 删除]        │
└─────────────────────────────────────────┘

较早保存（仅微弱光）：
┌─────────────────────────────────────────┐
│  "发现自己喜欢在安静的环境下思考"        │
│  2026-07-29 22:30 · 来自树洞对话        │  ← 几乎无光晕
└─────────────────────────────────────────┘
```

卡片左侧的"光晕条"代表这条知识的新鲜度（按保存时间衰减），不干扰文字可读性。

## 三、氛围层设计（区域 C — 仅在沉浸态出现）

### 3.1 AI 思考/加载态

```
┌──────────────────────────────────────┐
│                                        │
│      ●        ●                       │  ← 5~8 颗萤火虫随机分布
│           ●                           │     缓缓上浮（20s循环）
│    ●                ●                 │     每颗独立明灭周期
│                                        │
│        ●      ●                       │
│                                        │
│        "正在思考你的问题..."           │
│                                        │
└──────────────────────────────────────┘
```

**萤火虫参数**（仅在氛围区出现）：

| 属性 | 值 |
|:-----|:----|
| 数量 | 5-8 颗随机分布 |
| 大小 | 4-6px 直径（极小，不抢眼）|
| 颜色 | `rgba(74, 222, 128, 0.3~0.6)` 随机 |
| 呼吸周期 | 每颗 2-4s 独立随机 |
| 运动 | 缓慢飘浮，垂直范围 ±15px，水平 ±8px |
| 速度 | 一上一下约 20s 循环 |
| 透明度叠加 | 单颗最大 0.6，不累加（不会变亮到刺眼）|

### 3.2 空态

```
┌──────────────────────────────────────┐
│                                        │
│         🗺 还没有图谱数据              │
│                                        │
│         继续记录日记，AI 会自动提取     │
│                                        │
│       [💬 去树洞聊一聊]               │  ← 主按钮有萤火虫光晕
│                                        │

│                                        │
└──────────────────────────────────────┘
```

空态比加载态更暗（萤火虫更少、更淡），引导主按钮发光更明显。

## 四、明暗控制策略

### 核心原则

```
内容文字区域：          交互区域：              氛围区域：
████████████████        ████████████           ████████████
██ 白底/浅底  ██        ██ 萤火虫层 ██          ██ 深色底  ██
██ 文字清晰  ██        ██ 不影响阅读 ██         ██ 沉浸感  ██
████████████████        ████████████           ████████████
阅读为主                交互为主                情绪为主
```

这个分离确保任何一个区域不会因为"氛围牺牲阅读"或"阅读牺牲氛围"。

### 四层叠加效果

```
┌─ 内容层（最高对比度，文字可读性优先）─────────────┐
│  --text-primary: 高对比度                          │
│  --bg-primary: 浅/中亮                             │
├─ 交互反馈层（半透明，叠加在内容层之上）──────────────┤
│  光晕 rgba(74, 222, 128, 0.1~0.8)                │
│  不影响下层文字阅读                                │
├─ 氛围层（最深，只出现在沉浸态）──────────────────────┤
│  AI思考、空态、加载态                              │
│  5-8 颗萤火虫 4-6px                               │
└──────────────────────────────────────────────────┘
```

## 五、luminescence 动效时序矩阵

| 交互元素 | 触发 | 响应延迟 | 发光形态 | 持续时间 | 衰减曲线 |
|:---------|:-----|:---------|:---------|:---------|:---------|
| 主按钮 | hover | 50ms | 光晕扩散 4→12px | 持续 | ease-out |
| 主按钮 | click | 0ms | 闪光 15%→80% 色温变金 | 300ms | 快速衰减 ease-out |
| 主按钮 | disabled | — | 光晕消失，仅`opacity-40` | — | — |
| 图标按钮 | hover | 50ms | 背景 0→10% 圆形 | 持续 | ease-out |
| 图标按钮 | click | 0ms | 背景 10%→30% 闪光 | 250ms | 快速衰减 |
| 引导 chip | hover | 80ms | 边缘光晕扩散 | 持续 | ease |
| 引导 chip | click | 0ms | 中心闪光脉冲扩散到边缘 | 200ms | ease-out |
| Tab 切换 | click | 0ms | 光水平移动到新 Tab（200ms） | 200ms | ease-in-out |
| AI 气泡 | appear | 0ms | 边缘光从左流入 | 300ms | ease-out |
| 用户气泡 | appear | 0ms | 右侧滑入无光效 | 200ms | ease-out |
| Toast | appear | 0ms | slide-up + 边发光 | 200ms | ease-out |
| Toast | disappear | 3s | opacity 渐隐 | 300ms | ease-in |
| 氛围萤火虫 | enter | 0ms | 随机呼吸周期 2-4s | 持续 | 循环 |
| 删除确认 | appear | 0ms | fadeIn + scale | 200ms | ease-out |
| 对话框光 | focus | 80ms | 边框光晕 r=2→6px | 250ms | ease-out |

> 注意：此矩阵是给 lamda 实现的"动效行为参考"，不是参数规范。前端的实现可以调整具体数值以达到"感觉对了"为准。

## 六、设计选项（请 futao 选择，而不是回答开放式问题）

### 选项 1：闪光风格

| 版本 | 描述 | 感觉 |
|:-----|:-----|:------|
| **A 宁静闪烁** | 萤火虫缓慢呼吸（3-5s 周期），点击时闪一次才恢复 | 更安静、克制、不打扰日记阅读 |
| **B 活跃闪光** | 每秒都有 1-2 颗萤火虫随机亮一下（非点击触发），点击时爆发性强 | 更有生命感，但操作区更醒目 |

**我的建议**：选 **A**。日志软件阅读时间 > 操作时间，频率太高的闪光会打扰阅读。

---

### 选项 2：氛围萤火虫密度

| 版本 | 场景 | 数量 |
|:-----|:-----|:------|
| **A 克制** | 仅 AI 思考态显示 5-8 颗漂浮 | 加载态出现，完成后消失 |
| **B 常态** | 树洞聊天区始终有 2-3 颗极淡萤火虫漂浮（不抢眼） | 始终存在但几乎注意不到 |

**我的建议**：选 **A**。B 可能让用户觉得界面"永远在动"，看久了会累。少量不要，要不就不要。

---

### 选项 3：预览方式

| 版本 | 描述 |
|:-----|:------|
| **A 先确认方向再开发** | 你看完这份设计稿，确认方向和上面的选项就行。我出简化规范给 lamda 实现 |
| **B 做交互 Demo 你看效果再定** | 我先做一个单页面的"动效操作台"，你点各个按钮就能看到发光/闪光/漂浮效果，确认了再让 lamda 集成进 app |

**我的建议**：选 **A**。B 虽然能让你看到效果，但多一轮编码和反馈周期。A 的话方向对就往下走，细节让 lamda 按规范微调，调完你验收就行。
