## 1. 设计定位

### 继承 futao-homepage 的设计语言
```
雨林深绿 + 暗色夜空 + 金色点缀
    ↓ 适配方
卡片日记 UI：更轻量、更工具化、保留温暖感
```

### 核心关键词
- **温暖自然** — 延续雨林绿，但更柔和（适合每日写作）
- **卡片式阅读** — 信息层级清晰，呼吸感充足
- **极简聚焦** — 去除冗余装饰，内容优先
- **双模式友好** — 亮色/深色皆可

- 竖屏：时间线竖排（方案2）

- 保持一致的数据源，不同展现形式

## 5. 主题系统方向

### 双模式结构

```
theme/
├── tokens.css          # 语义 Token 定义
│   ├── --bg-primary    # 背景色
│   ├── --bg-card       # 卡片色
│   ├── --text-primary  # 正文字色
│   ├── --accent        # 主色调
│   └── --radius-card   # 形状 Token
│
├── light.css           # 亮色模式值
├── dark.css            # 深色模式值
│
└── index.ts            # 导入 + 切换逻辑
```

### 语义化 Token（推荐方式）
不用硬编码色值，使用 CSS 变量：
```css
:root {
  --bg-primary: #f5f2ed;
  --bg-card: #ffffff;
  --accent: #16a34a;
}
[data-theme="dark"] {
  --bg-primary: #0f1a12;
  --bg-card: #16231a;
  --accent: #4ade80;
}
```
