Spec · 交付

给 lamda 的实现规格

这是视觉语言定义，不是参数表。按这里的质感、层级和动效感觉编码，具体数值可微调。

布局 · 层叠卡片

  • 卡片错落堆叠（sticky-stack），后暗前亮形成水面纵深
  • 背景卡片暗（#172a45），前景卡片亮（玻璃雾 #4a6a94）
  • 卡片间留 48-96px 呼吸，拒绝平铺网格
  • 宽空白优先：padding: 96-140px 区块间距

玻璃质感

  • backdrop-filter: blur(28px) saturate(160%)
  • 内高光 inset 0 1px 0 rgba(255,255,255,0.12) 模拟折射
  • 描边用波光 rgba(168,208,255,0.22)，不用纯白
  • 不支持 backdrop-filter 时回退实色 #21395c

动效 · 弹簧

  • 统一弹簧曲线 cubic-bezier(0.34, 1.56, 0.64, 1)
  • 按压 scale(0.96) 瞬间压缩，松手过冲回弹
  • 卡片进入从水下浮起（translateY(60px) → 0）
  • 涟漪扩散 scale 0.35 → 1.6，7s 循环

色彩纪律

  • 只用 10 色，不引入第 11 种
  • 月金 #ffd9a0 仅在触发瞬间出现
  • 正文 #e2ecfa 对底 #0c1626 ≥ 9:1
  • 玻璃下的文字垫实色底，保证稳定可读
