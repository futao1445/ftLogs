01

先读这段：为什么不是照抄

futao 明确要求：你不能照抄我的设计，而是合理运用里面的元素。

意思是：这个页面是"设计语言的演示"，不是"最终 UI 的像素级模板"。你要做的不是把 HTML 原样复制进项目，而是理解这套设计语言的规则，然后把它应用到 AI 树洞的真实界面。

下面这套语言规则，是你要带走的"内功"。

02

这套设计在讲一个故事

池塘涟漪 = 深夜的池塘。所有视觉元素都在服务这个场景：

  • 深水区（页面底层）→ 沉底的回忆，安静、暗、有分量
  • 水面（中层卡片）→ 被记起的片段，一层层浮上来
  • 波光（前景/交互）→ 正在发生的事，最亮、最鲜活
  • 月光（月金点缀）→ 情绪触动的霎那，稀缺、珍贵

铁律：暗在下，亮在上；沉的东西暗，活的东西亮。

03

设计语言的 4 层

第 1 层 · 配色系统 = 角色分工

十色锁定，任何元素不得引入第 11 种颜色（硬规则）。

角色值用途面积
深海夜#0c1626页面底色60%
中层水#172a45卡片底层12%
近水面#21395c卡片中层10%
水界线#2d4a75边框/分隔4%
玻璃雾#4a6a94前景玻璃5%
水光蓝#6fb4ff主交互3%
波光#a8d0ff高光 / AI2%
浪花白#e2ecfa正文2%
晨雾#8fa6c4次级文字1.5%
月金#ffd9a0触发瞬间0.5%

你要理解的不是色值，是逻辑：

  • · 蓝阶（深海夜 → 波光）= 水的纵深，越浅越接近用户、越亮
  • · 文字只有两种：浪花白（正文）+ 晨雾（辅助），对比度全过 AA
  • · 月金是硬规则：只在"触发的霎那"出现（点击闪光、完成回弹），平时不占画面。它的稀缺就是它的价值

第 2 层 · 宽空白 = 在哪呼吸

硬规则：区块间距 96-140px，卡片之间留足呼吸。拥挤是廉价感的第一来源。

  • · Hero 区：大留白（padding 96px 起），只放一个完整场景
  • · 分节之间：120px 上下留白
  • · 卡片内部：26-30px 内边距，文字不贴边
  • · 可发挥：具体留白可微调，但"宁可多留，不可拥挤"是红线

第 3 层 · 层叠卡片 = 水面纵深

这是 futao 点名喜欢的，务必用好。

层级逻辑（硬规则）：后暗前亮。

  • · 最深的卡：#172a45，几乎贴背景，是"沉底记忆"
  • · 中层卡：#21395c + 玻璃雾，微微浮起
  • · 前景卡：玻璃质感（backdrop-filter: blur(28px) saturate(160%)），最亮，是"正在发生"
  • · 每张卡微微旋转（±3°）错开，避免对齐的死板。hover 浮起（-8px）+ 旋转回正

可发挥：卡片数量、内容、旋转角度按真实数据调整，但"层叠 + 后暗前亮 + 玻璃前景"的结构不能丢。

第 4 层 · 弹簧动画 = 水的性格

硬规则：所有动效走弹簧曲线 cubic-bezier(0.34, 1.56, 0.64, 1)，不用线性渐变。

  • · 按压：scale(0.96) 瞬间压缩，松手回弹过冲 4%
  • · 卡片进入：从水下浮起（translateY(60px) → 0），像水波把它推上来
  • · 涟漪：点击处一圈圈扩散（scale 0.35 → 1.6，透明消失）

可发挥：动画时长可微调（0.4-0.7s 都合理），但"弹簧回弹 + 过冲"的感觉不能丢，绝不能退回线性 ease。

第 5 层 · 结构落地（本轮验收硬指标）

这是 2026-07-31 futao 验收点名不合格后补的硬规则。只换配色和动效 ≠ 用设计稿。结构语言必须真实进界面：

  • ① 首页首屏 = 层叠卡片场景（必须）
    3 张真实日记卡错落浮起（后暗前亮 + ±3° + 前景玻璃 + hover 浮起回正 + 进入从水下浮起）。不是窄栏时间线平铺列表。首屏大留白 padding 96px 起，宽布局（max-w 1240 级）。时间线/标签/统计移到首屏场景之下
  • ② 对话类界面 = 玻璃前景场景（必须）
    树洞聊天窗用 pond-premium 前景玻璃卡语言（blur 28px + 内高光 + 波光描边），不是全宽平铺窗口
  • ③ 水波涟漪 = 通用交互（必须）
    写日记 / 发送 / 保存 / tab 切换，所有主操作统一涟漪反馈，不是只做一处
  • ④ 宽空白节奏真实出现（必须）
    区块间距 96-140px 要能看得见，拒绝贴边拥挤

审查基准：每一 commit 第一位核对"这页的设计意图 vs 设计稿意图是否一致"（结构/留白/层级），细节（色值/动效参数）第二。

04

硬规则 vs 可发挥

⛔ 硬规则（不能破）
  • 只用 10 色，不引入第 11 种
  • 月金只做触发瞬间
  • 区块间距 96-140px 大留白
  • 卡片后暗前亮 + 层叠 + 玻璃前景
  • 弹簧曲线 + 回弹过冲
  • 文字对比度全过 WCAG AA
  • 首页首屏 = 层叠卡片场景（非列表）
  • 对话界面 = 玻璃前景场景
  • 涟漪贯穿所有主操作
🛠 可发挥（按真实情况调）
  • 具体卡片用哪档蓝
  • 触发动画的具体形态
  • 具体某区块的留白大小
  • 卡片数量 / 内容 / 旋转角度
  • 动画具体时长 0.4-0.7s
  • 字号 / 字重组合
