NIGHT POND · DESIGN DIRECTION

涟漪页 Banner 重构 · 方向稿

futao：「设计稿里的涟漪大标签页带图案没有用于真实网页挺可惜，包括文案 涟.漪 / 把心里的话，投进水里。水面泛起一圈圈光，有人在水下，静静听。设计得挺好，能不能合理融入涟漪窗口中，稍微重构一下」

设计稿基准（pond-round4-direction.html 页面02）：kicker「NIGHT POND · TALK TO THE WATER」+ 涟.漪 64px 超细字标 + 三行文案 + 涟漪同心圆图案（4 圈 radial-gradient）+ 右上角月光光晕。本稿给出 3 个融入方向，均沿用 10 色体系 + 玻璃对话窗 + 弹簧，非硬贴。
方向 A

页首水镜 · 常驻窄条

一句话：涟漪对话窗顶部加一条「水镜 banner」——涟.漪 字标 + 同心圆图案常驻，文案精炼为一到两行，对话内容在下方流动。图案始终可见，仪式感不占屏。

方向 B

引导仪式 · 无会话全屏

一句话：保留设计稿完整仪式感——进入涟漪页且尚无会话时，banner 以整幅形式呈现（涟.漪 44px + 完整三行文案 + 同心圆居中 + 月光 + 引导标签），点任一标签即落入对话，有会话后 banner 收起为顶部窄条。

方向 C

水波沉浸 · 对话即涟漪

一句话：最克制——涟漪字标缩进对话窗头部（涟漪圆环 + 字标 + 一句话 tagline），同心圆图案淡为对话窗背景角落；三行文案不再常显，改为一则「涟漪小诗」在引导态居中轻显，对话时消失，让图案与文案都退为水的气质而非贴纸。

三个方向的取舍：A「页首水镜」最直接，设计稿图案 100% 呈现，适合 futao 想完整看到设计稿效果；B「引导仪式」最有仪式感，把「涟漪=投石入水」的叙事做到极致，但 banner 只在无会话时全幅；C「水波沉浸」最克制高级，图案退为背景、字标融入头部，但设计稿图案不完整呈现。
miky 推荐：方向 B——涟漪页的本质是「向水投话」，无会话时的全幅仪式最贴合产品叙事；进入对话后 banner 收起不干扰阅读，兼顾 futao「合理融入 + 稍作重构」。若 futao 更想保留设计稿图案的完整性，则方向 A。
