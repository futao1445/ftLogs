知识图谱 · 小鱼游荡

每条鱼是一段回忆（实体）。它们在水里慢慢游，游过处泛起水纹。点中一条——它变作月金色的鱼，与它相连的回忆如涟漪般浮现。

设计说明：几何玻璃小鱼（非手绘生物，延续「禁手绘生物SVG」纪律）——身体是玻璃感的椭圆光斑，尾巴摆动呼吸；颜色 = 实体类型（人物水光蓝 / 事件波光 / 地点浪花白 / 情绪晨雾 / 话题玻璃雾），大小 = 关联日记数。
月金纪律：选中瞬间才出现月金，泛一圈水纹后鱼保持月金色（常驻的只有这一条被选中的鱼），其余鱼仍走类型色。
