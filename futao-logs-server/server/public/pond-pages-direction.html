其他页，单独设计

树洞页做得好，不动。但首页 hero 以下 + 日历/搜索/AI总结/知识库，现在还是 max-w-2xl 的平铺标签——同一个"窗口"换个内容。 这一稿给每个页面一个专属的池塘叙事，每页有自己的空间性格，而不是套同一个模板。

现状：全部 max-w-2xl 窄栏 现状：平铺标签，无空间感 目标：每页一种池塘叙事 五页五性 · 同一种水
页面 01
日历 · 纵向水草日历

现在日历是单月表格，窄窄一条。改成纵向水草——左侧是一列月份（水草茎），中间是当日水面格，选中一天右侧浮出一张玻璃回忆卡。 翻月像拂过水草，点日像石子落水。

空间叙事

  • 左侧月份列 = 水草茎，翻月柔滑
  • 格子 = 水面，有日记的泛水光点
  • 点日 = 右侧玻璃回忆卡浮起

交互

  • 翻月 = 水草随动微摆
  • 点日 = 涟漪环 + 回忆卡浮起
  • 今天 = 月金描边（稀缺）

性格

  • 时间是有纵深的水
  • 月度导航 + 日详情同屏
  • 信息密度保持但呼吸感增强

改动

  • 容器 max-w-2xl → max-w-5xl
  • 左栏月份列 + 右侧详情卡
  • 网格换水面色 + 光点
一句话硬规则：日历 = 纵向水草——左侧月份茎、中间水面格、右侧玻璃回忆卡，点日泛涟漪，今天月金描边。
页面 02
搜索 · 倒映水镜

搜索现在是一行输入框 + 平铺结果。改成向水面投石——搜索框是水面上的镜面，输入时水面微颤； 结果像水底浮起的回忆，命中词泛光，每条带一个涟漪分数圈。空态是静水面。

空间叙事

  • 输入框 = 水面镜，输入微颤
  • 结果 = 水底浮起的回忆
  • 底部涟漪 = 思考中的呼吸

交互

  • 输入防抖 = 水面渐起微波
  • 真实筛选：非命中不出现
  • 关联度 = 涟漪分数圈

性格

  • 搜索是有仪式感的打捞
  • 语义搜索契合"水底回忆"
  • 比列表更有叙事温度

改动

  • 搜索框玻璃化 + 镜面
  • 仅浮现命中回忆（修复"显示全部"）
  • 命中词波光高亮
一句话硬规则：搜索 = 向水面投石——镜面搜索框、结果仅浮现命中回忆（非命中不出现）、命中词波光高亮、关联度涟漪圈。
页面 03
AI 总结 · 水面分层浮标

AI 总结现在是一个窄条 + 胶囊按钮。改成分层水面——每级总结是一层水（浅层=一句话/中层=要点/深层=全文）， 生成时该层泛起水波进度（不再是转圈），完成后浮起。知识图谱沉在底部一层（承接小鱼图谱）。

空间叙事

  • 每级总结 = 一层水，深色下沉
  • 生成中 = 水波进度条
  • 图谱 = 水底最后一层

交互

  • 选级 = 该层浮起
  • 生成 = 水波从浅层荡到深层
  • 图谱 = 沉底可展开

性格

  • 总结 = 越深越沉、越贵
  • 进度可见，不空白等待
  • 图谱天然沉底，层级有序

改动

  • 三级总结纵向分层
  • 进度水波条替转圈
  • 图谱沉底一层
一句话硬规则：AI 总结 = 水面分层——浅/中/深三层浮标，生成时水波进度，图谱沉底一层。
页面 04
知识库 · 沉底记忆瓶

知识库现在是「平铺标签 + 词条列表」，只像是普通数据库。改成池底记忆瓶——每条记忆是一支玻璃瓶，安静沉在池底， 瓶里浮着一粒月金微光（这条记忆的光）。hover 瓶子浮起，点开底部浮出一张玻璃记忆卡（内容 + 它关联的回忆标签）。 记忆是沉底的宝贝，不是平铺的条目。

空间叙事

  • 每条记忆 = 一支玻璃瓶沉在池底
  • 瓶内月金微光 = 这条记忆的光
  • 池底砂石光点 = 沉底氛围

交互

  • hover 瓶子浮起微荡
  • 点瓶 = 底部玻璃记忆卡浮出
  • 关联回忆 = 标签 chips 可直接跳图谱

性格

  • 记忆 = 沉底的宝贝，有重量感
  • 直接承接知识图谱的小鱼语言
  • 月金微光是稀缺点缀

改动

  • 列表 → 玻璃瓶阵列
  • 点瓶浮出详情卡
  • 关联 chips 与图谱互跳
一句话硬规则：知识库 = 池底记忆瓶——每条记忆一支玻璃瓶沉底、瓶内月金微光，hover 浮起、点开浮出玻璃记忆卡。
页面 05
首页下方 · 纵贯水线

首页 hero 之下的时间线现在是窄窄一条竖排。改成纵贯水线——时间线贯穿一条中央水线（涟漪光柱）， 日期像水面的月影，每组日记是一串浮出水面的玻璃卡。hover 时卡片随水波微漾。

一句话硬规则：首页下方 = 纵贯水线——中央涟漪光柱、日记浮出玻璃卡、hover 随波微漾、宽布局对齐首屏。

四页四性，同一种水

日历是水草、搜索是水镜、总结是水层、时间线是水线——每页有自己的空间叙事，但共用同一套水语言（10 色 / 玻璃 / 涟漪 / 弹簧 / 禁生物 SVG）。

方向确认后，我按每页单独落代码 + 每页一份交互参数给前端实现。AI 树洞页保持不动。
