整体布局，用 taste-skill 重构

池塘涟漪的首屏已经对了——宽留白、层叠卡片、玻璃前景。但往下滚，时间线还是 max-w-2xl 的窄栏，图谱/知识库埋在二级入口里。 这一稿解决的是「整面湖」的问题：从首屏到内容区，布局要一体、宽、有呼吸。

三个方向 · 同一个故事（水面之上轻声对话，水面之下沉底回忆）· 三种讲法

方向 A

满湖 · Full Lake

把整个产品当成一面完整的湖——导航是湖岸线，内容区全部展开成湖面，宽到能呼吸。不再有「首屏宽、内容窄」的断层。

布局轴

  • 导航玻璃通栏拉满全宽，不再窄条
  • 内容区统一 max-w-1400 + padding 96px
  • 日记时间线改双栏：左日期柱 + 右玻璃卡
  • 图谱/知识库从二级入口提升为首页「浮岛」

  • 点浮岛 = 水波泛开，滑向对应 tab
  • 点日期柱 = 浮出那天所有日记

性格

  • 工具感 + 高级感的平衡
  • 信息获取效率最高
  • 改动可控，风险最低
一句话硬规则：全站同一张湖面——导航、首屏、内容区全部 max-w-1400 同宽对齐，区块间距 96-140px，四个模块以玻璃浮岛在首页可见。
方向 B

浮岛群 · Archipelago

首页就是一汪湖面，五个功能模块是错落分布的玻璃浮岛。你在湖心环视，伸手点哪座岛，哪座岛就浮起到眼前。

  • 点岛全屏展开该功能，回岛沉回湖面
  • 图谱/树洞/知识库同级，没有埋藏
  • 信息架构扁平化

交互叙事

  • 入岛 = 水波从指尖泛开，玻璃面板浮起
  • 离岛 = 面板沉回水面，回到湖心
  • 湖心岛常驻今日概览 + 一句树洞问候

性格

  • 展示型 · 探索型用户最爱
  • 「一屏看全部」的掌控感
  • 改动最大，最接近品牌故事
一句话硬规则：首页一屏即全部——五个玻璃浮岛错落分布，点岛水波浮起全屏展开，模块无埋藏、同级可见。
方向 C

水层 · Depth Layers

把池塘的物理深度变成信息层级——滚动就是下潜。水面之上和 AI 对话，水面写日记，水底翻回忆。每一层的水色都不同。

布局轴

  • 纵向三水层，滚动即下潜
  • 每层背景色阶递进（近水面→中层水→深海夜）
  • 导航固定在「水面高度」，随滚动微折射
  • 区块间距 140px 大呼吸

交互叙事

  • 写日记 = 一颗石子入水，涟漪扩散
  • 滚到哪层，哪层水色浮起
  • 树洞在上（对话）、日记在中（记录）、回忆在下（沉底）

性格

  • 最沉浸 · 最「池塘」
  • 品牌故事直接变成物理结构
  • 情感型用户共鸣最强
一句话硬规则：页面纵向分三水层——树洞在浅水面（近水面色）、日记日历在水面（中层水色）、图谱搜索沉水底（深海夜色），滚动下潜，色阶递进。

我的建议

如果 futao 要的是「高级、贵、一眼是池塘」——方向 C 水层最贴品牌故事，且改动量中等； 如果还要兼顾「像正常工具，好找功能」——方向 A 满湖最稳，模块提升但结构保守。 方向 B 最自由但首页重构最重，适合 futao 想彻底换气质时。

三个方向共用同一套硬约束：10 色锁定、max-w-1400、区块 96-140px、玻璃前景 blur28px、弹簧曲线、涟漪贯穿主操作、禁手绘生物 SVG。
